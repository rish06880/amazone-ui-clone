"# amazone-ui-clone" 

A frontend clone of the Amazon homepage built using HTML and CSS.

## Technologies used....
- HTML
- CSS
- Flexbox
- Font awesome

## features....
- amazon inspired navigation bar
- search bar
- hero section
- product category
- multi-column footer
- clean and user friendly UI
- amazon like homepage layout
- built using flexbox for layout
- organized HTML and CSS structure
- provide comments in code for easy understanding
